# 문자열 계산기

## 개요
입력받은 문자열에서 숫자를 추출하여 합계를 계산하는 계산기 구현

## 기능 명세

### 기본 기능
- 구분자로 분리된 숫자들의 합 계산
- 빈 문자열 입력 시 0 반환

### 구분자 규칙

#### 기본 구분자
- 쉼표(`,`)
- 콜론(`:`)

#### 커스텀 구분자
- 형식: `//[구분자]\n[본문]`
- 문자열 앞부분의 `//`와 `\n` 사이에 위치하는 문자가 커스텀 구분자로 지정됨
- 예: `//;\n1;2;3` → 구분자는 `;`, 결과는 6

### 예외 처리
- 잘못된 입력값의 경우 `[ERROR]`로 시작하는 메시지와 함께 Error 발생
- 에러 발생 시 애플리케이션 종료

## 입출력 사양

### 입력
- 구분자와 양수로 구성된 문자열

### 출력
- 계산된 덧셈 결과

## 동작 예시

### 기본 구분자 사용
```
입력: ""        → 출력: 0
입력: "1,2"     → 출력: 3
입력: "1,2,3"   → 출력: 6
입력: "1,2:3"   → 출력: 6
```

### 커스텀 구분자 사용
```
입력: "//;\n1;2;3"  → 출력: 6
```

### 실행 예시
```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```

## 구현
1. 입력 string 아닌 경우 예외 처리
2. 커스텀 구분자가 있는지 확인. 있으면 변수에 할당 없으면 기본 구분자 할당 
3. 입력 구분자와 숫자를 제외한 나머지가 들어간 경우 예외 처리. 단, "."은 소수점으로 쓰인 경우 용인함(양수로 구성된 문자열 조건)
4. 3번 과정에서 동시에 누적합도 진행
